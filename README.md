### 🚀 About Me

Full-stack developer specializing in **ASP.NET Core Web API** and **Angular**, with a focus on clean, scalable architecture. I build end-to-end systems — from Entity Framework Core-backed REST APIs secured with JWT and rotating refresh tokens, to zoneless Angular frontends built with Signals, RxJS, and Tailwind CSS.

I follow **Clean Architecture** and **SOLID principles**, structuring backends into layered projects with repository/service patterns, and back them with unit tests, SQL Server, and Redis caching. I've also implemented real-time features with **SignalR** (live chat, typing indicators, notifications) and containerized full production stacks with Docker, Serilog, and Seq for observability.
